# RAX: scaling online exploration, compiling decisions into programs (2026)

`[rax-2026]` · Huang, Zhang, Chen et al., arXiv 2610.22496 · status: verified · local: `data/refs/rax-2026.html`

Read 2026-10-24 from the arXiv HTML. Every number is theirs. Lines starting "For us" are our reading.

## Setup

- A coding agent (Claude Code with Claude Opus 5.5 at xhigh effort; Codex with a GPT-6 model on five tasks) controls robots through perception and control SDKs: no action demos, no hand-made primitives, no value function. Depth and force are exposed.
- **Compile step:** the agent first acts through tool calls. After task success it compiles the decision sequence into a staged program (check preconditions → move → verify outcome). Measured values (grasp orientation, gait distance) become program parameters.
- **Hand-back:** the program runs unattended in new scenes; on a perception or planning failure it raises an exception and the agent steps in.
- **Memory:** in-session notes; across sessions a skill repository (code, when it applies, execution evidence). A skill enters only after it ran successfully without supervision.
- Exploration is parallelised across agents and environments. Embodiments: single arm, bimanual, dexterous, mobile, humanoid; sim and real (Franka FR3).

## Results

- Five simulation benchmarks: +37.4 points over the best baselines on average. RoboDojo (7 tasks): 78.3% vs 24.9% for the best leaderboard policy. Performance grows with exploration budget (sessions of 2 to 32 exploration episodes; the final program is scored alone on unseen evaluation scenes).
- **Cost falls as decisions move into code:**

  | Task | First success | Compiled |
  |---|---|---|
  | BEHAVIOR-1K load car (sim) | 123 min inference, 254k output tokens | 4 min, 4k tokens |
  | RoboDojo make toast (sim) | 17 min inference | 6 s per episode |
  | Air fryer (real Franka) | 72.3 min, 262.4k tokens | 18 s, 2.0k tokens |
  | Bandu tower (real Franka) | 17.2 min, 88.4k tokens | 10 s, 2.2k tokens |

- **Peg-in-hole (ManipulationNet, real FR3):** the agent fit the board CAD to the wrist image, probed by touch for holes, and entered 0.1 mm-clearance holes corner-first with a tilt, then rocked the peg upright. All three pegs seated (19.7–21.0 of 21.8 mm). It worked by direct tool calls under user supervision and **never ran an unattended program for this task**; the operator taped the board down and reset jammed pegs. Full run about 55 min.

## For us

- This is the published version of our System 2 → System 1 claim, with the curve we want to show: inference time and tokens per episode drop by one to two orders of magnitude once a program runs.
- Their gate (unattended success with evidence) and their hand-back (program raises, agent steps in) map directly onto our promote and demote rules.
- The precision insertion is the part they did not compile. If our insertion skills compile, that goes beyond RAX; if they do not, RAX predicts it.
- Report inference time separately from environment time, as they do; robot time barely changed while inference fell.
