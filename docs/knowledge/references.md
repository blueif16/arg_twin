### Claims we were given, checked against the primary source

| Claim (as given) | Status | What the source says |
|---|---|---|
| ASPIRE (Goldberg, Shi, Zhu, Fan): execution engine with fine-grained traces, skill library of validated fixes, evolutionary search over tasks and programs; 31% vs 4% on unseen long-horizon LIBERO-Pro; sim skills on a real bimanual robot cut reasoning tokens | verified, with corrections | First author is Runyu Lu; Goldberg, Shi, Zhu and Fan are co-authors. Search is over programs; a coordinator orders tasks as a curriculum. 31% vs 4% correct (library from LIBERO-90). Real-robot savings are total and output tokens to the first successful program (e.g. 61.9M → 6.6M), not reasoning tokens specifically [aspire-2026] |
| Agent as Policy: ≥80% in 7 of 8 real configs; Codex and Claude Code; saved experience sped execution; experience given to a weaker model raised success and cut time and tokens | verified | Terra 1/5 → 4/5, time −34%, tokens −11%. Authors note the repeated-run speedup is uncontrolled [agp-2026] |
| HERO, "Practice Makes Policies": zero human demos to "robot muscle memory" | verified | Figure 1: "from zero human demonstration to robot muscle memory"; Li et al. (SJTU); real Franka, Gemini-3-Flash [hero-2026] |
| "Pigey" (Dhruv Shah, Tri Dao): reasoning loop over frozen VLA skills, LIBERO-PRO 12.8% → 53.3% | verified | First author Liane Galanti (Princeton, Together AI); backends are frozen π0.5 and a TAMP grasp planner [pigey-2026] |
| Show-Harness: written conventions give most of the grounding; action names are only a prior | verified | One 2×2 ablation, Gemini-3.1 Pro, Block/Banana → Plate, 20 trials [show-harness-2026] |
| Astra stalls at insertion: 2/20 on Robocurve | verified in part | 2/20 correct; Astra "reaches the groove and stalls". Per-trial grades: only 10/20 got above the groove [robocurve-astra-2026] |
| 40% real on GPT-GEAR | verified, needs context | 40% is overall zero-shot real success across 5 tasks (10/25); block-in-cup insertion alone is 2/5, and 4/5 with one example [gpt-gear-2026] |
| Su et al., "GPT 6 Astra as an Embodied Policy" | secondhand link | GitHub report by the Galbot group, cited in [urai-2026]; we read the arXiv version, [galbot-astra-2026] |
| URAI: agent-written tools 18% → 53%; deciding after each call 56% vs 24% for a program written in advance | verified | [urai-2026] |
| XLeRobot: body model plus synced demos cut task time 57–69% | verified | 57.4% (geometry + camera info) and 68.6% (synchronized images, actions, states), separately; one task, 3 trials per condition [xlerobot-2026] |
| Hierarchical planner: synchronous planning leaves the arm moving 28.7% of the time | verified | Fast Plans, π0.5-style waypoint hierarchy on a real dual-arm robot [fastplans-2026] |
